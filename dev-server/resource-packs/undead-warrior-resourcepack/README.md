# Undead Warrior Resource Pack

This resource pack makes wolves with "Undead Warrior" names look like wither skeletons.

## Installation Instructions:

### Method 1: Simple Texture Replacement (Recommended)
1. **Download the wither skeleton texture** from Minecraft
2. **Save it as `wolf.png`** in the `assets/minecraft/textures/entity/wolf/` folder
3. **Zip the entire `undead-warrior-resourcepack` folder**
4. **Rename the zip to `undead-warrior-resourcepack.zip`**
5. **Place it in your Minecraft `resourcepacks` folder**
6. **Enable it in Minecraft settings**

### Method 2: OptiFine CIT (Advanced)
If you have OptiFine installed:
1. The CIT properties file is already included
2. It will automatically make wolves with "Undead Warrior" names look like wither skeletons
3. Other wolves will remain normal

## How to Get the Wither Skeleton Texture:

### Option A: Extract from Minecraft
1. Open Minecraft
2. Go to Resource Packs
3. Click "Open resource pack folder"
4. Navigate to `assets/minecraft/textures/entity/skeleton/`
5. Copy `wither_skeleton.png`
6. Rename it to `wolf.png` and place it in this pack's wolf folder

### Option B: Download Online
1. Search for "Minecraft wither skeleton texture"
2. Download the 16x16 or 32x32 version
3. Save as `wolf.png` in the wolf folder

### Option C: Use Vanilla Tweaks
1. Go to vanillatweaks.net
2. Download the wither skeleton texture
3. Use it as the wolf texture

## Testing:
1. Connect to your server
2. Create an Undead Warrior wolf using the Hades Scythe
3. The wolf should now look like a wither skeleton!

## Troubleshooting:
- Make sure the texture is named exactly `wolf.png`
- Ensure the file is in the correct folder path
- Check that the resource pack is enabled in Minecraft
- Restart Minecraft if changes don't appear immediately
