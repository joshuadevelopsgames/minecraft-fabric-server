# AI Mythology - Complete Greek Mythology Mod

A comprehensive Minecraft mod that brings the full Greek mythology experience to life with gods, creatures, quests, and divine systems.

## 🌟 Features Overview

### 🏛️ Complete Olympian Pantheon
- **12 Olympian Gods**: Zeus, Poseidon, Hades, Athena, Ares, Apollo, Artemis, Hermes, Hephaestus, Aphrodite, Demeter, Dionysus
- **Divine Favor System**: Build relationships with gods through actions and offerings
- **God-Specific Rewards**: Each god grants unique abilities and blessings
- **Divine Interventions**: Gods actively help or hinder players based on favor

## 🎮 Commands and Controls

### Favor Commands
- `/aimyth favor check <god>`: Check favor with a god
- `/aimyth favor give <player> <god> <amount>`: Grant favor
- `/aimyth favor reset <player>`: Reset all favor

### Quest Commands
- `/aimyth quest start <quest>`: Begin a quest
- `/aimyth quest progress`: Check quest progress
- `/aimyth quest complete <quest>`: Complete a quest

### Creature Commands
- `/aimyth creature summon <creature>`: Summon a creature
- `/aimyth creature tame <creature>`: Tame a creature
- `/aimyth creature release <creature>`: Release a creature

### Portal Commands
- `/aimyth portal create <type>`: Create a portal
- `/aimyth portal travel <destination>`: Travel through portal
- `/aimyth portal close`: Close active portal
