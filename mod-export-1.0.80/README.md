# Greek Mythology Mod v1.0.80

🏛️ **Bring the power of the Olympian gods to your Minecraft world!**

## 📖 Overview
The Greek Mythology Mod adds legendary weapons and divine powers inspired by ancient Greek mythology.

## ⚡ Features
- **Hades Scythe:** Soul-powered weapon with live damage display
- **Zeus Bolt:** Lightning weapon with flight abilities  
- **Poseidon Trident:** Water-controlling divine weapon
- **Inferno Pearls:** Area corruption projectiles (NOW FIXED!)
- **Favor System:** Gain favor with 12 Olympian gods
- **NEW:** /soul clear command for resetting Hades Scythe

## 🔧 Installation
1. Install Fabric Loader for Minecraft 1.21.8
2. Download Fabric API 0.129.0+
3. Place greek-mythology-1.0.80.jar in mods folder
4. Launch and enjoy!
