# 🎮 Undead Warrior Resource Pack - Quick Start

## ✅ What's Ready:
- **Server-side mod** is deployed and working
- **Resource pack structure** is created
- **Setup script** is ready to run

## 🚀 Quick Setup (3 Steps):

### Step 1: Get the Texture
1. **Open Minecraft**
2. **Go to Resource Packs**
3. **Click "Open resource pack folder"**
4. **Navigate to:** `assets/minecraft/textures/entity/skeleton/`
5. **Copy:** `wither_skeleton.png`

### Step 2: Add to Resource Pack
1. **Rename:** `wither_skeleton.png` → `wolf.png`
2. **Copy to:** `undead-warrior-resourcepack/assets/minecraft/textures/entity/wolf/wolf.png`

### Step 3: Install Resource Pack
1. **Zip the folder:** `undead-warrior-resourcepack/`
2. **Rename:** `undead-warrior-resourcepack.zip`
3. **Place in:** Your Minecraft `resourcepacks` folder
4. **Enable in:** Minecraft settings

## 🎯 Test Your Undead Warriors:

1. **Connect to:** `localhost:25565`
2. **Get scythe:** `/give @s greekmyth:hades_scythe`
3. **Find skeleton** and hit it with scythe (while it has wither effect)
4. **Verify:** Wolf should look like wither skeleton!

## 🔧 Current Features:
