# Greek Mythology Modpack v1.0.66

## Features
- **Hades Scythe**: Powerful weapon with Soul Harvest, Underworld Portal, and Death Mist abilities
- **Undead Warriors**: Transform skeletons into loyal undead warrior pets
- **Custom Textures**: Beautiful custom undead warrior appearance
- **Wither Effects**: Undead warriors apply wither effects to enemies

## Installation
1. **Install Fabric Loader** for Minecraft 1.21.8
2. **Install Fabric API** (included in modpack)
3. **Extract this modpack** to your Minecraft mods folder
4. **Install the resource pack** `undead-warrior-resourcepack` in-game
5. **Start Minecraft** and enjoy!

## How to Use
1. **Get the Hades Scythe**: `/give @s greekmyth:hades_scythe`
2. **Find a skeleton** and hit it with the scythe (while it has wither effect)
3. **Transform it** into your undead warrior pet
4. **Watch it follow you** and attack your enemies!

## Mod Size
- **Mod JAR**: 1.7MB (well under 15MB limit)
- **Resource Pack**: ~3.4MB
- **Total**: ~5.1MB

## Requirements
- Minecraft 1.21.8
- Fabric Loader 0.16.14+
- Fabric API 0.129.0+
- Java 17+
